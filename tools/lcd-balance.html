LCD Balance

Drag this window onto the flickering display, then press F for fullscreen. Keep this page open for the whole process: reloading loses the frame parity it tracks.

Check: a flat grey. The panel's leftover charge shows as flicker. Nudge the slider until the flicker is as faint as you can get it. The further from 0 you need to go, the stronger the charge. Write the number down; it should shrink as the display recovers.

Null0
This is a full-screen 30 Hz strobe. Do not look at it. Turn the display away or cover it before starting, and do not run it where anyone sensitive to flashing light can see it.

It lights the frames of one parity only, the opposite of whatever built up the charge. Which parity that is can only be found by trying: run Phase A for a few minutes, then go back to Check. If the null number moved toward 0, keep going with A; if it moved away, switch to Phase B.
